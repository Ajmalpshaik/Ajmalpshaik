I deliver MEP BIM on both the consultant and the contractor side — HVAC, plumbing, drainage,
firefighting and water supply. The part that sets my work apart is what happens around the model:
**I build the automation my team runs on.** It started as AutoLISP routines to stop repeating
drafting work by hand, grew into a full Revit add-in suite, and is now AI agents that do real
modelling work inside a live model.
